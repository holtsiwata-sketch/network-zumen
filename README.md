# LAN配線系統図エディタ

ブラウザで動く「構内情報通信網 系統図」(LAN配線系統図)の作図ツール。ビルド不要。
共聴系統図エディタ(../kyocho_zumen)と同じ作りにしている。

## 起動
`.claude/launch.json` の `network-zumen`(python http.server 8766)。index.html を直接開いても動く。

## できること
- 階ごとのレーンに機器を置き、出力端子(橙)から入力端子(緑)へドラッグして配線する。出力端子からは何本でも引ける。
- 図記号は国交省「公共建築設備工事標準図」p.11 と JIS C 0303 に従う(RT/SW/情報用アウトレット 壁付・床付・二重床/電話用アウトレット/MDF/PBX/内線電話機)。JIS に記号がない機器は、四角に略号(ONU, FW, HUB, PP, AP, CAM, SV, PC, MFP, TV, STB)で表す。
- ケーブル: UTP Cat5e/6/6A、光 SM/MM(心数)、電話用構内ケーブル、パッチコード。本数・長さ・配管を傍記する。
- 線種(JIS C 0303): 実線=天井隠ぺい、破線=床隠ぺい、点線=露出、一点鎖線=地中。光ファイバは太線。
- アウトレットの識別子を自動で振る(TIA-606 の fs-an に準じる。書式は図面設定で変更可、例 `3F-B-01`)。
- 下部タブ: 配線表(コネクタ1口ごと。CSV 出力あり)、ポート・PoE集計、数量表、図記号・線種。
- チェック: UTP 90m 超/100m 超、MM 300m 超、ポート・SFP 不足、PoE 容量超過・非対応 SW からの給電、コネクタ数とケーブル本数の不一致、未接続。
- 選択すると図の上(スマホでは下)に操作バーが出る: 配線(L キー)→接続先をタップ/クリック、詳細、複製、削除。配線の端子は位置関係から自動で選ぶ。
- スマホ: パレットは上部の横スクロール、表は「表」ボタン、設定・チェックは下から出るシート。2本指で拡大縮小・移動。
- 保存は JSON。SVG/PNG 出力、Excel(.xlsx: 配線表・ポート/PoE集計・ケーブル数量・機器数量・チェック結果の5シート)、CSV、印刷(A3 横、図+配線表)。

## ファイル
- js/lib.js  図記号・ケーブル定義・チェック/集計・識別子の採番
- js/app.js  UI
- js/sample.js  サンプル(3階建て事務所)
- js/xlsx.js  外部ライブラリなしの .xlsx 書き出し(無圧縮 ZIP)
- RESEARCH.md  調査ノート

js/css を変えたら index.html の `?v=` を上げる(ブラウザのキャッシュ対策)。
